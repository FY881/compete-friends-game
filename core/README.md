# حاجز كرّات الانهيار (Core-dump guard)

هذا المجلد موجود **عن قصد** ولا يحوي أي كود.

## لماذا؟

إعداد النواة في هذه البيئة هو `core_pattern = core`، أي أن **أي عملية تنهار داخل المشروع
تكتب ملف انهيار باسم `core` في مجلد العمل** — وقد حدث فعلاً: ملف بحجم **1.1 جيجابايت**
من انهيار `bunx vite build` ملأ مساحة العمل (2.1 جيجا → 1.1 جيجا بعد حذفه) وساهم في
توقف البيئة.

وجود **مجلد** بهذا الاسم يجعل النواة تفشل في كتابة ملف الانهيار (لا يمكن الكتابة فوق مجلد)،
فتُحفظ المساحة تلقائياً بدل أن ينتفخ المشروع مرة أخرى.

> لا تحذف هذا المجلد، وإذا ظهر ملف باسم `core` في جذر المشروع فاحذفه فوراً.
